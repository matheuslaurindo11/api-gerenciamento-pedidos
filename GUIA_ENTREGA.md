# Guia rápido para testar e entregar

1. Instale Node.js 18+ se ainda não estiver instalado.
2. Extraia o ZIP e abra um terminal dentro da pasta `api-gerenciamento-pedidos`.
3. Rode `npm install`.
4. Rode `npm test` e confira se todos os testes passam.
5. Rode `npm start`.
6. No Postman, importe `postman_collection.json` e execute as requisições.
7. Faça as cinco capturas reais listadas no README e salve-as em `evidencias/`.
8. Crie um repositório no GitHub e envie o projeto com pelo menos cinco commits significativos ao longo do desenvolvimento.
9. Revise a seção “Uso de IA” para refletir exatamente o seu processo e certifique-se de que sabe explicar as camadas, validações e testes.

A API armazena dados em memória: reiniciar o servidor apaga os pedidos.
